{%- comment -%} site.tags is core Jekyll, no plugin needed: a hash of tag name to posts. The pages themselves come from jekyll-archives. Sorted by name, not by count. Iterating site.tags yields [name, posts] pairs, so `sort: "size"` tries to index a pair by a string and raises; a bare `sort` orders by the first element. Alphabetical is also easier to scan when you are looking for one subject, and the count is on each chip anyway. {%- endcomment -%} {%- assign tags = site.tags | sort -%}
